# Landing Page — Ganhe dinheiro com IA

## Instalar
```
npm install
```

## Rodar localmente
```
npm run dev
```
Abra http://localhost:8080

## Alterar o link do WhatsApp
Edite `src/lib/whatsapp.ts` (número e mensagem).

## Build
```
npm run build
```

## Publicar na Netlify
1. Suba o projeto para o GitHub.
2. Na Netlify: "Add new site" → "Import from Git" → escolha o repositório.
3. Build command: `npm run build` · Publish directory: `dist/client`.
4. Clique em Deploy.

## Favicon
Substitua `public/favicon.ico` pelo seu ícone.
